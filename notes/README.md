# Notes

Working notes: grilling sessions, domain-modeling exploration, raw design thinking. Obsidian-flavored markdown (wikilinks, callouts, frontmatter) — open this folder as an Obsidian vault if that's useful, but nothing here depends on Obsidian being installed.

This folder is **not authoritative**. It's where decisions get worked out; where they land is `docs/`:

- A resolved product/domain question → update [docs/design/phase-1-overview.md](../docs/design/phase-1-overview.md)'s open questions (strike through, link back here for the full reasoning).
- A new or changed term → [docs/CONTEXT.md](../docs/CONTEXT.md).
- An architectural decision → a new entry in [docs/adr/](../docs/adr/).
